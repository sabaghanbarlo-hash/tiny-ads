# Tiny ads

Instagram ad videos (1080x1920) for **Tiny Japanese** and **Tiny French**, built with each channel's own scenes, characters and edge-tts voices.

Run the **Render ads** workflow (Actions tab). It checks out `tiny-japanese-video` and `tiny-french-video` (read-only), renders both ads and saves them to `out/`.
Nothing here posts to Instagram and nothing in the other repos is changed.
